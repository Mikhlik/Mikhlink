# Контекст проекта Mikhlink



## Почему появился этот проект



Проект Mikhlink создаётся для решения реальной задачи.



Автор проекта много лет занимается мобильными IRL-трансляциями и использовал различные схемы передачи видео через несколько интернет-соединений.



Наиболее удачным решением оказалась связка Moblin + Moblink на macOS.



После перехода на Windows выяснилось, что полноценного аналога этой связки практически не существует.



Именно поэтому было принято решение создать собственный открытый проект.



---



# Практическая задача



Главная задача проекта — обеспечить максимально устойчивую передачу видеопотока во время мобильного стриминга.



Во время движения автомобиля качество различных интернет-соединений постоянно меняется.



Одни соединения могут ухудшаться, полностью пропадать или восстанавливаться.



Пользователь не должен замечать подобных событий в трансляции.



---



# Основная идея



Mikhlink не создаётся ради красивой архитектуры.



Архитектура существует только для достижения практической цели:



максимально стабильной передачи видеопотока.



Если два решения дают одинаковый результат, предпочтение отдаётся более простому.



---



# Целевая платформа



Основная целевая платформа:



Windows.



Разработка ведётся под WSL2 с использованием CMake и C++17.



---



# Статус проекта



Проект находится на самом раннем этапе.



На данный момент выполнено:



- создан GitHub-репозиторий;

- настроен Git;

- настроен CMake;

- создан минимальный проект;

- выполнена первая успешная сборка;

- выполнен первый push.



Настоящая реализация ещё впереди.



---



# Что не является целью проекта



Проект не является:



- VPN;

- заменой Speedify;

- тестом сетевой скорости;

- учебным примером по C++;

- экспериментом ради эксперимента.



Все решения должны приносить практическую пользу реальному IRL-стримеру.



---



# Долгосрочная цель



Создать открытое решение, позволяющее пользователям Windows получить возможности, сопоставимые с лучшими существующими инструментами для мобильного стриминга, при этом сохранив прозрачную архитектуру, качественную документацию и возможность дальнейшего развития сообщества.
