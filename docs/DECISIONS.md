# DECISIONS.md



# Журнал архитектурных решений



## Назначение



Этот документ хранит все важные технические решения проекта.



Каждое решение получает уникальный номер.



Решения никогда не удаляются.



Если решение позднее признано ошибочным, оно остаётся в истории с пометкой, что заменено новым.



---



# D-001



## Тема



GitHub является главным источником истины проекта.



## Причина



История чатов не должна быть единственным местом хранения информации.



Все важные сведения должны храниться в репозитории.



---



# D-002



## Тема



Документация хранится внутри репозитория.



## Причина



Любой новый разработчик или ИИ должен иметь возможность понять проект без чтения старых переписок.



---



# D-003



## Тема



Разработка ведётся небольшими проверяемыми этапами.



## Причина



После каждого этапа проект должен оставаться рабочим.



Это значительно упрощает поиск ошибок и уменьшает риск поломки проекта.



---



# D-004



## Тема



Speedify не является архитектурной основой проекта.



## Причина



Проект создаётся как практическая замена рабочему процессу Moblin + Moblink для Windows.



Speedify был протестирован и признан неподходящим для реальной задачи автора проекта.



---



# D-005



## Тема



Основная документация ведётся на русском языке.



## Причина



Это основной язык автора проекта.



При необходимости позже может быть создана английская версия документации.
