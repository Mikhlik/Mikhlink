# Архитектура проекта Mikhlink



## Назначение



Этот документ описывает устройство проекта.



На текущем этапе большинство решений являются предварительными.



Архитектура должна уточняться по мере разработки.



---



# Предварительная структура



Mikhlink предположительно будет состоять из нескольких крупных компонентов.



## Core



Основная логика программы.



---



## Network



Работа с сетевыми соединениями.



---



## Bonding Engine



Логика объединения нескольких интернет-каналов.



---



## Transport



Передача данных между узлами.



---



## OBS Integration



Интеграция с OBS Studio.



---



## User Interface



Графический интерфейс пользователя.



---



## Configuration



Загрузка и сохранение настроек.



---



## Logging



Журналирование и диагностика.



---



# Принципы архитектуры



- Минимальная связанность компонентов.

- Чёткое разделение ответственности.

- Возможность независимого тестирования.

- Минимум платформозависимого кода.

- Простота сопровождения.



---



# Важно



Этот документ будет активно изменяться.



Никакая предварительная схема не считается окончательной до появления работающих прототипов.
